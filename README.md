# SmartRoute - DAA Microproject

An intelligent dynamic vehicle routing, garbage clearance, and traffic management system optimizing routes using Dijkstra's algorithm, priority queues, and real-time scheduling.

## Features
- **DAA Pathfinding**: Dijkstra's Algorithm simulation with dynamic congestion weights.
- **Admin Dashboard**: Live route management, truck dispatch, and zone status tracking.
- **User Portal**: Issue reporting, collection status, and community updates.
- **Responsive Web UI**: Built with modern CSS, glassmorphism, and responsive design.

## How to Run
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
