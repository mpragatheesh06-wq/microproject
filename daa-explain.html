📊 Weighted Cost Formulation

$$\text{Edge Cost } C(u,v) = d(u,v) \times (1 + \alpha \cdot T_{traffic}) + \beta \cdot \frac{1}{\text{Beds}_{avail}}$$

Where \(d(u,v)\) is Euclidean distance, \(T_{traffic}\) is real-time congestion index, and \(\text{Beds}_{avail}\) penalizes full hospitals.

2. Algorithm Execution Steps (Min-Heap Priority Queue)

Step 0
Initialize Min-Heap Priority Queue \(Q = \{(A, 0)\}\), distance array \(dist[v] = \infty\), \(dist[A] = 0\).

3. Dijkstra Shortest Path Pseudocode

1: function Dijkstra(Graph G, Source A, Target H):
2:   dist[A] ← 0, dist[v] ← ∞ for all v ≠ A
3:   PQ.insert(A, 0)
4:   while PQ is not empty do:
5:     u ← PQ.extractMin()
6:     if u == Target then break
7:     for each neighbor v of u do:
8:       weight ← calculateWeightedCost(u, v)
9:       if dist[u] + weight < dist[v] then:
10:        dist[v] ← dist[u] + weight
11:        parent[v] ← u
12:        PQ.decreaseKey(v, dist[v])
13:  return reconstructPath(parent, Target)

4. DAA Theoretical Complexity & Algorithm Analysis

Time Complexity

\(O((V + E) \log V)\)

Using a Binary Min-Heap Priority Queue where \(V\) is the number of road intersections/hospitals and \(E\) is road segments.

Space Complexity

\(O(V + E)\)

Requires memory to store the Adjacency List graph representation, distance array, and parent pointers.

Greedy Choice Property

Optimal Substructure

At each step, selecting the node with minimum tentative distance guarantees globally optimal shortest path without negative edges.

Dynamic Re-routing

\(O(E + V \log V)\)

When user selects a preferred hospital, the target node updates and the algorithm recalculates the optimal trajectory in sub-millisecond time.
